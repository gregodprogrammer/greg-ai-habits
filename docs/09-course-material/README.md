## Content Strategy

The course material should follow these principles:

1. **Project-first** — Build a real application, not toy examples.
2. **Pattern-focused** — Teach patterns that transfer to any stack (Repository, DI, Providers).
3. **AI-integrated** — Use Claude Code throughout and teach prompt engineering alongside software engineering.
4. **Beginner-accessible** — Assume no prior knowledge beyond basic HTML/CSS/JavaScript.
5. **Production-grade** — Everything taught should be how real software is built professionally.
