## How to Use This Section

When you encounter an error:

1. Check the [TROUBLESHOOTING-INDEX.md](TROUBLESHOOTING-INDEX.md) first — the issue may already be documented.
2. If not found, investigate and document the issue in the index with:
   - Error message.
   - Root cause.
   - Resolution steps.
   - Date resolved.
3. Reference the troubleshooting entry in the session journal.

This prevents the same issue from being investigated twice across different Claude Code sessions.
