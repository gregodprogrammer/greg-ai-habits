## Diagram Tools

Recommended tools for creating diagrams:

| Tool | Use For |
|---|---|
| [draw.io](https://app.diagrams.net) | Architecture diagrams, ER diagrams |
| [Mermaid](https://mermaid.js.org) | Sequence diagrams, flowcharts (embeddable in Markdown) |
| [Excalidraw](https://excalidraw.com) | Hand-drawn style architecture sketches |
